# Bongo Ocean Backend

Bongo Ocean is a global B2B & B2C vendor marketplace platform, in the spirit of Alibaba — connecting suppliers, vendors, and buyers on one system. This backend powers the public storefront and the staff dashboard behind it.

It securely manages customer and staff authentication, product catalog data (products, categories, brands), supplier and stock/inventory management, orders, customer accounts, verified reviews, and profile information.

It also stores customer and visitor support conversations, delivers real-time chat updates, provides period-based order, revenue, delivery, and best-selling product analytics, and records a full activity log audit trail of staff actions across the platform.

The backend keeps the storefront and dashboard connected through a central API and MongoDB database, with role-based access for customers, managers, administrators, and super administrators.
