# Fish Me Aqua Backend

The Fish Me Aqua Backend powers the public website and staff dashboard. It securely manages customer and staff authentication, products, categories, orders, customer accounts, verified reviews, and profile information.

It also stores customer and visitor support conversations, delivers real-time chat updates, and provides period-based order, revenue, delivery, and best-selling product analytics for the dashboard.

The backend keeps website and dashboard information connected through a central API and MongoDB database with role-based access for customers, managers, administrators, and super administrators.
